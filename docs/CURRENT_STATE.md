# Current state

Текущая версия собрана заново по сводному ТЗ GP27 и проверена по структуре репозитория.

## Реализовано
- роли: Руководитель, Экономист/Бухгалтер, Администратор;
- анкеты по месяцу, сотруднику, должности, занятости, плановым/фактическим часам и критериям;
- статусы: черновик, отправлено, возврат на доработку, утверждено;
- стоимость балла, расчёт выплаты и Excel-экспорт;
- печатная ведомость Руководителя с 5 строками «Член комиссии»;
- поиск по ФИО у Администратора;
- управление подразделениями, должностями, критериями, баллами и учётными записями;
- удаление и скрытие анкеты Администратором.

## Критическое правило скрытия
Скрытая анкета остаётся видимой Администратору для снятия признака, но исключается из видимости Руководителя и Экономиста/Бухгалтера, из ИТОГО, итоговых сумм, report_rows(), подготовки печати, печати и Excel-экспорта.

## Исправления ревизии
- Руководитель больше не может создать анкету в чужом подразделении подменой формы.
- После отправки анкеты Руководитель не может менять её до возврата на доработку.
- Исправлено сохранение полей в момент действия «Отправить на проверку».
- Excel создаётся во временном файле, а не как рабочий файл репозитория.
- Windows-запуск работает независимо от текущей папки.
- Добавлена панель администрирования.

## Данные
Рабочие файлы stim_bonus_data_v5.json и stim_bonus_hidden_v1.json не публикуются в репозитории.
