# GP27 Stim Bonus

Программа расчета стимулирующих надбавок СПб ГБУЗ «ГП №27».

## Правила разработки

- Все изменения ведутся через GitHub.
- Рабочие данные сотрудников (`stim_bonus_data_v5.json`) и локальные файлы скрытия (`stim_bonus_hidden_v1.json`) не публикуются в репозитории.
- При правках сохраняется существующий пользовательский функционал, если в задаче явно не указано иное.
- Каждое изменение фиксируется в README/истории коммитов.

## Текущая задача

Исправить механизм скрытия анкеты Администратором так, чтобы скрытая анкета у ролей Руководитель и Экономист:

- не отображалась в сводной ведомости;
- не участвовала в строке «ИТОГО»;
- не участвовала в итоговых суммах;
- не попадала в «Подготовку печати»;
- не попадала в печатную ведомость.

У Администратора скрытая анкета должна оставаться видимой, чтобы галочку «Не отображать анкету» можно было снять.
