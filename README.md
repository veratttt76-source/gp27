# GP27 Stim Bonus

Программа расчёта KPI и стимулирующих выплат СПб ГБУЗ «Городская поликлиника №27».

## Назначение

Система предназначена для заполнения, расчёта, проверки и печати анкет KPI сотрудников ГП27.

## Роли

### Руководитель
- заполнение анкет сотрудников;
- просмотр общего балла;
- формирование ведомости для ознакомления сотрудников;
- печатная форма с 5 строками «Член комиссии».

### Экономист / Бухгалтер
- доступ ко всем анкетам;
- стоимость балла и расчёт выплаты;
- возврат анкеты на доработку;
- редактирование заполненной формы;
- экспорт данных.

### Администратор
- редактирование критериев, значений и баллов;
- управление учётными записями;
- поиск и фильтрация по ФИО в сводной ведомости;
- удаление анкет;
- управление признаком «Не отображать анкету».

## Анкета KPI

Основные поля:
- месяц;
- ФИО;
- должность;
- плановые часы;
- фактические часы;
- основное место работы / совместительство;
- критерии по должности.

Ориентировочно используется около 30 должностей и до 12 критериев на должность. Значения критериев — 0 или 2 балла.

## Расчёт

Базовая формула:

```
итог = сумма баллов / (план × факт)
```

Расчётная логика должна изменяться только в рамках согласованной задачи.

## Сводная ведомость и ИТОГО

Скрытая Администратором анкета:
- остаётся доступной Администратору для управления;
- не отображается у Руководителя и Экономиста;
- не участвует в строке «ИТОГО»;
- не участвует в итоговых суммах.

## Печать

Скрытые анкеты не должны попадать:
- в «Подготовку печати»;
- в `report_rows()`;
- в печатную ведомость.

## Данные

Рабочие данные сотрудников (`stim_bonus_data_v5.json`) и локальные файлы скрытия (`stim_bonus_hidden_v1.json`) не публикуются в репозитории.

## Правила разработки

- Все изменения ведутся через GitHub.
- Не изменять существующий пользовательский функционал, если это прямо не предусмотрено задачей.
- Перед изменением проверять затрагиваемые участки кода.
- Каждую согласованную правку фиксировать отдельным коммитом.
- Существенные изменения фиксировать в README и истории коммитов.
